# Grade Analyzer
this is a simple Python project using oop


Grade Analyzer is a command-line Python application that allows users to manage and analyze student grades. The project was built to practice core Python concepts including object-oriented programming, functions, loops, file handling, and JSON data storage.

## Features

- Add students with their name and grade
- View all students and their pass/fail status
- Calculate the average class grade
- Find the highest grade
- Find the student with the highest grade
- Display students who passed
- Search for a student by name
- Save student data between sessions using JSON

## Concepts Practiced

- Classes and objects
- Object-oriented programming (OOP)
- Methods and attributes
- Functions
- Loops and conditionals
- Lists and dictionaries
- User input handling
- Error handling with `try/except`
- Reading and writing JSON files

## How It Works

Students are represented as objects using the `Student` class. Each student object stores information such as name and grade, and includes methods to determine whether the student passed.

Student data is converted into dictionaries and stored in a JSON file so that information is preserved after closing the program.
